# Development Documentation

This directory contains documents related to the development, planning, and architecture of BenchPRO.

## Directory Structure

- **`master_plan.md`**: The primary document and single source of truth for the ongoing development roadmap, project status, and strategic goals. **All developers should start here.**

- **`reference/`**: Contains documents describing key architectural assessments and design decisions that are still relevant. These are not active plans but provide context for why the system is built the way it is.

- **`archive/`**: Contains outdated, completed, or superseded planning and development documents. This directory serves as a historical record of the project's evolution.
