# BenchPRO Reference Documentation

Welcome to the BenchPRO reference documentation. This section provides detailed information about the various components and modules in BenchPRO.

## Contents

- [Testing System](testing/testing.md): Centralized test data management, fixtures, and testing best practices.
- [Utility Modules](utils/index.md): Common utility modules used throughout BenchPRO.
- [Configuration System](config/index.md): Schema-based configuration management and validation.
- [Executor System](executor/index.md): Task execution and composition architecture.
- [Template System](templates/index.md): Block-based template composition for script generation.
- [Workspace System](workspace/index.md): Workspace management and module file creation.

## How to Use This Documentation

This reference documentation is organized by module and component. Each page provides:

- An overview of the component or module
- Detailed information about its design and implementation
- Examples of how to use it
- Best practices for working with it

If you're new to BenchPRO, you might want to start with the [User Guide](../user_guide/index.md) instead, which provides a more high-level overview of the system.
