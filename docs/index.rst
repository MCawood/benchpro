Architecture Overview
-------------------

BenchPRO follows a clean, domain-driven design architecture with clear separation of concerns:

* **Domain Layer**: Core business logic and entities
* **Infrastructure Layer**: Technical implementations and external system integrations
* **Application Layer**: Use case implementations and service orchestration
* **Interface Layer**: User interfaces (CLI, API) and external system adapters
